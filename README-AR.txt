تحديث صلاحية STORE_KEEPER - CashBox Cloud

هذا التحديث يحتوي فقط على الملفات المعدلة، حتى لا يستبدل سجل Git الحالي عندك.

النتيجة:
1) STORE_KEEPER يرى لوحة مستودع فقط، بدون الرصيد والإيرادات والمصروفات.
2) يعرض رصيد الكروت والأساور من قاعدة البيانات.
3) يعرض إدخال اليوم واستهلاك اليوم لكل صنف.
4) يعرض آخر حركة للمستودع.
5) يضيف صفحة إدخال للمخزون: /inventory/stock-in
6) يبقي صفحة الاستهلاك اليومي: /inventory/consumption
7) يمنع STORE_KEEPER من API لوحة الصندوق المالية على مستوى Backend.

تحديث الخزينة والتحويلات والتقارير المرنة - 2026-08-30

1) إضافة قسم الخزينة والتحويلات للمستخدمين الماليين فقط.
2) شاشة إدخال يومي للبنوك والمحافظ والعهد والموردين والتحويلات.
3) الحركة الواحدة يمكن توزيعها على تولان والملقا، مثل 5000 من هلا تولان + 5000 من هلا الملقا.
4) إضافة حسابات البنوك والمحافظ مع رصيد بداية وتاريخ بداية ورصيد بعد آخر حركة.
5) إضافة متابعة العهد: مصروف، مسترد، مسوى، وقائم لكل مندوب ولكل جهة.
6) إضافة تقرير شامل لأي فترة: يوم، 3 أيام، أسبوع، شهر، أو فترة مخصصة.
7) التقرير يجمع الصندوق + الخزينة الخارجية + العهد + البنوك والمحافظ + المخزون.
8) يدعم تقرير تولان فقط، الملقا فقط، أو الاثنين معًا.
9) المصروفات والإيرادات الخارجية ترتبط بدليل الحسابات مثل الكهرباء والنقل والشحن والضيافة.
10) MANAGER وCEO يستطيعان تعديل وحذف حركات الخزينة مع سجل مراجعة، وACCOUNTANT يستطيع الإدخال والعرض.
11) STORE_KEEPER لا يرى هذا القسم ولا أي بيانات مالية.
12) الجداول الجديدة في TiDB تُنشأ تلقائيًا عند أول تشغيل بعد النشر؛ لا يحتاج SQL يدويًا.
